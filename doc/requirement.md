# tabex 要求仕様

## 概要

tabex は Windows 標準エクスプローラの代わりに使うファイルマネージャである。

- Rust で実装し、起動が速く、メモリ消費の少ない軽快な動作を目指す。
- 「ワークスペース」機能を中心に据える。ワークスペースとは、複数のフォルダをまとめて開き、タブで切り替えられる作業単位のことである。名前を付けて保存しておき、あとからいつでも同じ構成を開き直せる。
- 左右 2 ペイン表示とし、それぞれのペインが独自のタブ列を持つ。
- Windows シェルと統合し、エクスプローラと同じ右クリックメニュー・アイコン・サムネイルを使える。

## 要求仕様

### 1. 動作環境・実装制約

- 対象 OS: Windows 10 (22H2) 以降 / Windows 11、x64（ARM64 は将来対応）
- 実装言語: Rust（stable toolchain）
- GUI: `windows` crate（windows-rs）経由で Win32 API / COM を直接使う。Web ランタイム（WebView2 など）や大型の GUI フレームワークには依存しない。
- 配布形態: インストール不要の単一 exe で動作すること（インストーラは任意）
- 高 DPI（Per-Monitor V2）に対応すること
- 日本語のファイル名・パス・IME 入力（リネーム時など）を正しく扱えること
- 長いパス（260 文字を超えるパス）を扱えること

### 2. 性能目標

| 項目 | 目標 |
|---|---|
| 起動から操作可能になるまで（コールドスタート、前回ワークスペース復元を含む） | 300ms 以内 |
| 待機時のメモリ使用量（ワーキングセット） | 50MB 以下 |
| 10 万件のファイルを含むフォルダを開いたとき | UI が固まらないこと（列挙はバックグラウンドで行い、終わった分から順に表示する） |
| フォルダ移動・タブ切替の応答 | 体感で遅延がないこと（目安 100ms 以内） |

- ファイル列挙・アイコンやサムネイルの取得・ファイル操作は UI スレッドとは別のスレッドで行う。
- 一覧表示は仮想化し、画面に見えている行だけを描画する。

### 3. ウィンドウ構成

- メニューバーは置かない。ウィンドウの最上部にツールバーを置く（詳細は 3.1）。
- 1 つのウィンドウの中に、左右 2 つのペインを並べる。
  - ペインの境界はドラッグで幅を変えられる。
  - 1 ペイン表示にも切り替えられる。
- 各ペインは独自のタブ列を持ち、**1 タブ = 1 フォルダ** を表示する。
- 操作対象となるペインは常に 1 つで（アクティブペイン）、見た目で区別できる。
- 各タブには次の部品を備える。
  - アドレスバー（パンくず形式。クリックするとパスを直接入力できる）
  - 戻る / 進む / 上へ ボタン
  - ファイル一覧
- ウィンドウ左側にナビゲーションツリー（ワークスペース・ホーム・OneDrive・PC（ドライブ）・ネットワーク・ごみ箱と、それぞれのフォルダ階層）を置く。表示/非表示を切り替えられる。
  - ナビゲーションツリーの一番上に「ワークスペース」ノードを置き、その子として登録されているワークスペースを並べる（詳細は 5.6）。
  - OneDrive の項目は 3.2 で定める。
- ステータスバーに、項目数・選択している数・選択した項目の合計サイズを表示する。

#### 3.1 ツールバー

- ウィンドウの最上部（タイトルバーのすぐ下）に、ウィンドウの幅いっぱいの 1 行のツールバーを置く。常に表示し、隠す設定は設けない。
- ボタンはアイコンだけで表し、左から右へ 1 列に並べる。文字のラベルは出さない。機能のまとまりごとに区切り線を入れる。
- ボタンにマウスを乗せると、ツールチップに名前とショートカットキーを出す（例: `隠しファイル (Ctrl+H)`）。ショートカットキーは `config.toml` の `[keys]` で変えた割り当てを表示する。割り当てがなければ名前だけを出す。
- **ほかのペイン（タブバー・ナビゲーションツリー・ファイル一覧とその右クリックメニュー）やワークスペース一覧が備えている機能は載せない**。タブの操作はタブバー、ワークスペースの操作はナビゲーションツリーとワークスペース一覧、ファイルの操作はファイル一覧の右クリックメニューが受け持つ。ツールバーには、ほかのどこにもボタンやメニューがない機能だけを載せる。
- 載せるボタン（左から順に）:

| まとまり | ボタン | 種類 | 動き | 対応するキー |
|---|---|---|---|---|
| 移動 | ホーム | 普通のボタン（右クリックで一覧） | 左クリックでプライマリのホームディレクトリへ移動する。右クリックでホームディレクトリの一覧を出し、選んだフォルダへ移動する（3.3） | Alt+Home（プライマリへ移動） |
| 編集 | 元に戻す | 普通のボタン | 直前のファイル操作を元に戻す（7）。戻せる操作がないときは無効の表示にする | Ctrl+Z |
| 表示 | 表示モード | ドロップダウン | アクティブなタブの表示モードのアイコンを出す。押すと「大アイコン / 中アイコン / 小アイコン / 一覧 / 詳細」のメニューを出し、今のモードに印を付ける。選んだモードをアクティブなタブに適用する | Ctrl+Shift+1〜5 |
| 表示 | 隠しファイル | オン / オフ | 隠しファイル・システムファイルを表示するかを切り替える（6） | Ctrl+H |
| 表示 | ドットファイル | オン / オフ | ドットファイルを表示するかを切り替える（6） | Ctrl+Shift+H |
| 表示 | ファイル名拡張子 | オン / オフ | 拡張子を表示するかを切り替える（6） | なし |
| レイアウト | ナビゲーション ウィンドウ | オン / オフ | ナビゲーションツリーの表示 / 非表示を切り替える（3） | なし |
| レイアウト | 2 ペイン表示 | オン / オフ | 1 ペイン表示と 2 ペイン表示を切り替える（3） | なし |
| 更新 | 最新の情報に更新 | 普通のボタン | アクティブなタブの一覧を読み込み直す | F5 |

- オン / オフのボタンは、オンのときに押し込んだ表示にする。ショートカットキーで切り替えたときや、起動時に設定を読み込んだときも、すぐに表示を合わせる。
- 表示モードのボタンのアイコンは、アクティブなタブ・アクティブペインを切り替えたときや、ショートカットキーでモードを変えたときにも、すぐに合わせる。
- ホーム・元に戻す・表示モード・最新の情報に更新は、アクティブペインのアクティブなタブを対象にする。
- ボタンを押しても、キーボードのフォーカスはそれまでの場所（ファイル一覧など）から動かさない。Tab キーなどでツールバーにフォーカスを移すこともできない（ツールバーはマウスで操作する。同じ操作はすべてキーボードでもできる）。
  - 例外: フォーカスのあるナビゲーションツリーを隠したときは、見えないところにキー入力が届かないよう、アクティブなタブのファイル一覧にフォーカスを移す。
- 高 DPI に対応し、DPI に合わせた大きさでアイコンをくっきり表示する。ダークモードは OS の設定に従う程度にとどめる（10）。
- メニューバーにあった項目は、次の場所で操作する:

| メニューバーにあった項目 | 代わりの操作 |
|---|---|
| 新しいタブ / タブを複製 / タブを閉じる | タブバー（[+] ボタン、タブの右クリックメニュー、ダブルクリック、中クリック）、Ctrl+T / Ctrl+W |
| 閉じたタブを開き直す | Ctrl+Shift+T |
| 新しいフォルダー / プロパティ | ファイル一覧の右クリックメニュー、Ctrl+Shift+N / Alt+Enter |
| 切り取り / コピー / 貼り付け / 削除 / 名前の変更 | ファイル一覧の右クリックメニュー、Ctrl+X / Ctrl+C / Ctrl+V / Delete / F2 |
| すべて選択 | Ctrl+A |
| 終了 | ウィンドウの閉じるボタン、Alt+F4 |
| ワークスペース一覧 / 最近使ったワークスペース | Ctrl+Alt+W のワークスペース一覧（最近使った順に並ぶ）、ナビゲーションツリーの「ワークスペース」ノード |
| ワークスペースの新規作成 / 名前の変更 / 削除 | ナビゲーションツリーの右クリックメニュー（5.6）、ワークスペース一覧の右クリックメニュー |
| ワークスペースを名前を付けて保存 | 廃止。ナビゲーションツリーの「今の構成を元に新規作成...」で同じことができる（5.3） |
| 元に戻す、表示の各項目、最新の情報に更新 | ツールバー |

#### 3.3 ホームディレクトリとホームボタン

よく使うフォルダを「ホームディレクトリ」として `config.toml` に一覧で登録しておき、ツールバーの「ホーム」ボタンからすぐに移動できるようにする。

- 設定: `config.toml` に `[[homes]]` を並べて書く。1 つの `[[homes]]` が 1 つのホームディレクトリで、書いた順に並ぶ。**先頭がプライマリ**のホームディレクトリになる。
  - `path`（必須）: フォルダの絶対パス。ドライブのパス（`D:\work`）と UNC パス（`\\nas\share`）を書ける。`%USERPROFILE%` のような環境変数も使える。
  - `name`（省略可）: 一覧に出す名前。
  - 例は「使いかた」を参照。
- 設定がない場合（`[[homes]]` が 1 つもない、または使える項目が 1 つもない）は、ユーザーフォルダ（例: `C:\Users\me`）だけをホームディレクトリとして扱う。ホームボタンは常に使える。
- 使えない項目: `path` がない・空・相対パスの項目は使わない。その場合は、起動時にステータスバーへ「ホームディレクトリの設定が不正です: (項目の番号や内容)」と表示する（ほかの項目はそのまま使う）。
- 設定は起動時に読み込む。tabex を起動している間に `config.toml` を書き換えても、次に起動するまで反映しない。一覧を tabex の画面から編集する機能は設けない（`config.toml` を手で編集する）。
- 左クリック: アクティブなタブで、プライマリのホームディレクトリへ移動する。
  - 移動のしかたは、アドレスバーにパスを入力して移動したときと同じとする（戻るの履歴に積む、絞り込み表示を解除する）。
  - すでにそのフォルダを表示しているときは何もしない。
  - フォルダが存在しない（削除済み・ネットワークが未接続など）ときも、事前には調べずに移動し、タブには既存の「フォルダが見つかりません」の表示を出す（5.4）。
- 右クリック: ボタンのすぐ下にホームディレクトリの一覧をメニューで出す。
  - 項目は設定に書いた順に並べる。`name` があれば「名前」と「パス」を、なければ「パス」だけを表示する。プライマリかどうかの区別はつけない（先頭がプライマリ）。
  - アクティブなタブが表示しているフォルダと同じ項目には印を付ける。
  - 項目を選ぶと、左クリックと同じ動きでそのフォルダへ移動する。Esc やメニューの外のクリックで閉じたときは何もしない。
- キー: Alt+Home で、左クリックと同じくプライマリのホームディレクトリへ移動する。`config.toml` の `[keys]` で割り当てを変えられる（コマンド名は「使いかた」を参照）。ツールチップは「ホーム (Alt+Home)」とする。
- ホームディレクトリの設定は、ホームボタンと Alt+Home にだけ使う。最後のタブを閉じたときに開くフォルダや、新しいワークスペースの最初のフォルダ（いずれもユーザーフォルダ）は変えない。

#### 3.2 ナビゲーションツリーの OneDrive

エクスプローラと同じく、ナビゲーションツリーから OneDrive を開けるようにする。

- 最上位の並び: 「ワークスペース」→「ホーム」→ OneDrive の項目 →「PC」→「ネットワーク」→「ごみ箱」の順とする。
- 対象: この PC の OneDrive に設定されているアカウントをすべて、1 アカウントにつき 1 項目ずつ並べる。
  - 個人用（OneDrive - Personal）と、職場または学校用（OneDrive - 組織名）の両方を対象とする。職場または学校用のアカウントが複数あれば、それぞれを別の項目にする。
  - 並び順は、個人用を先にし、そのあとに職場または学校用を名前の自然順で並べる。
- 表示名とアイコンは、エクスプローラのナビゲーションウィンドウに出るものと同じにする（例: 雲のアイコンに「OneDrive - Personal」）。表示名は Windows（シェル）が返すものをそのまま使うため、環境によっては「（ユーザー名） - 個人用」のようになる。
- 項目を選ぶと、そのアカウントの同期フォルダ（例: `C:\Users\me\OneDrive`）を、**実際のフォルダとして**アクティブなタブで開く。
  - アドレスバーには実際のパス（パンくずなら `Users › me › OneDrive`）を表示する。ファイル操作・ドラッグ＆ドロップ・`:sh`・ワークスペースへの保存は、普通のフォルダと同じに扱う（ワークスペースには実際のパスを保存する）。
  - 展開すると子のフォルダを並べる。子の並べかた・隠しファイルとドットファイルの設定の効きかた・ドロップ先になることなど、ほかの操作はナビゲーションツリーのほかのフォルダの項目と同じとする。
- 表示しない場合:
  - OneDrive にアカウントが 1 つも設定されていなければ、OneDrive の項目は 1 つも出さない（何も通知しない）。
  - アカウントの同期フォルダが見つからない（削除・移動されているなど）場合は、そのアカウントの項目を出さない。
- 調べるタイミング: ナビゲーションツリーを作るとき（起動後、最初のアイドル時）にアカウントを調べる。tabex を起動している間に OneDrive へサインイン・サインアウトしても、次に起動するまでツリーには反映しなくてよい。起動時間（300ms 以内）には影響させない。
- ナビゲーションツリーを非表示にすると、OneDrive の項目も一緒に隠れる。
- 同期状態（雲・チェックマークなどのオーバーレイ）の表示は対象外とする（10）。

### 4. タブ操作

- タブを新しく開く（Ctrl+T）、閉じる（Ctrl+W）、切り替える（Ctrl+Tab / Ctrl+Shift+Tab / Ctrl+1〜9）
- ドラッグでタブの並び順を変えられる。タブを反対側のペインへ移すこともできる。
- フォルダを中クリックすると、そのフォルダを新しいタブで開く。
- 閉じたタブを開き直せる（Ctrl+Shift+T）。
- タブを複製できる。

### 5. ワークスペース

#### 5.1 定義

ワークスペースとは、名前の付いた「左右ペインのタブ構成」と「表示状態」の組である。

#### 5.2 保存・復元する情報

- ワークスペース名
- 左右それぞれのペインについて
  - タブの並び順と、各タブで開いているフォルダのパス
  - アクティブなタブ
  - 各タブの表示状態: 表示モード（詳細 / 一覧 / アイコン）、ソート列と昇順・降順、列の構成と列幅
- アクティブペイン、ペイン分割の比率、1 ペイン / 2 ペインの別

以下は保存しない: ファイルの選択状態、スクロール位置、戻る / 進むの履歴

#### 5.3 管理操作

- 新規作成: 空の構成か、今の構成を元に作る。今の構成を別名で複製したいときは「今の構成を元に新規作成」を使う（「名前を付けて保存」という操作は設けない）。
- 名前の変更、削除
- 切り替え: ショートカット（Ctrl+Alt+W で、最近使った順に並んだワークスペース一覧を表示）から選ぶ、ナビゲーションツリーの「ワークスペース」ノードから選ぶ（5.6）
- これらの操作は、ナビゲーションツリーの「ワークスペース」ノードとワークスペース一覧で行う。ツールバーには載せない（3.1）。

#### 5.4 保存と起動のふるまい

- 変更は自動で保存する。タブの開閉・移動、フォルダ移動、表示状態の変更をきっかけに、短い間隔で間引いて書き込む。
- 起動すると、前回最後に使っていたワークスペースを復元する。
- 1 つのウィンドウで同時に開けるワークスペースは 1 つだけ。切り替えると、今のワークスペースを保存してから次のワークスペースを読み込む。
- tabex は同時に 1 つしか起動しない（単一インスタンス）。すでに起動しているときに tabex.exe をもう一度実行すると、引数を起動中のウィンドウに渡してすぐ終了する。これにより、同じワークスペースファイルを複数のプロセスが同時に書き込むことを防ぐ。
- 復元時に、保存されているフォルダが見つからない場合（削除済み・ネットワークが未接続など）でも、ワークスペース全体の復元は止めない。該当するタブには「フォルダが見つかりません」と表示し、再試行と、一番近い親フォルダへ移動する操作を用意する。保存されているパスは書き換えない。

#### 5.5 保存形式

- 形式: TOML
- 保存場所: `%APPDATA%\tabex\workspaces\<ワークスペース名>.toml`（1 ワークスペースにつき 1 ファイル）
- アプリ全体の設定: `%APPDATA%\tabex\config.toml`（前回使っていたワークスペース名、ショートカット設定など）
- 利用者が手で編集したり、他人と共有したりできる形式とする。読み込めないファイルがあれば、そのファイルだけを使わずにエラーを通知し、アプリは起動を続ける。

#### 5.6 ナビゲーションツリーのワークスペースノード

- ナビゲーションツリーの最上位の先頭（ホームより上）に「ワークスペース」ノードを置く。その子として、登録されているワークスペースをすべて並べる。
  - 並び順は名前の自然順とする（最近使った順の一覧は Ctrl+Alt+W のワークスペース一覧が担う）。
  - ワークスペースの項目は末端の項目とし、その下にフォルダなどの子は持たない。
  - 読み込めないワークスペースファイル（5.5）は並べない。
- 項目をクリックすると、そのワークスペースに切り替える。キーボードで項目を選んだ場合も同様に切り替える（エクスプローラのナビゲーションツリーで項目を選んだときと同じ感覚）。切り替えのふるまいは 5.4 に従う（今のワークスペースを保存してから読み込む）。
  - すでに開いているワークスペースの項目を選んだときは何もしない。
- 今開いているワークスペースの項目は太字で表示し、ほかの項目と区別できるようにする。
- 右クリックメニュー:
  - ワークスペースの項目: 名前の変更、削除。削除するときは確認ダイアログを出す。今開いているワークスペースを削除することはできない（メニュー項目を無効にする）。
  - 「ワークスペース」ノード: 新規作成（5.3 と同じく、空の構成か今の構成を元にするかを選ぶ）
- ワークスペースの作成・名前の変更・削除・切り替えを行ったら（ワークスペース一覧、ツリー、起動引数のどこから行った場合でも）、ツリーの内容と太字表示をすぐに更新する。
- 「ワークスペース」ノードの展開 / 折りたたみの状態は `config.toml` に保存し、次回の起動時にも引き継ぐ。初回起動時は展開した状態とする。
- ナビゲーションツリーを非表示にすると、「ワークスペース」ノードも一緒に隠れる。

### 6. ファイル一覧表示

- 表示モード: 詳細（列表示） / 一覧 / アイコン（大・中・小）
- 詳細表示の列: 名前・更新日時・種類・サイズを標準とする。列の追加・削除、並べ替え、幅の変更ができる。
- 列見出しをクリックしてソートできる。名前は自然順（例: `file2` を `file10` より前に並べる）で並べる。
- 隠しファイル・システムファイル・拡張子を表示するかどうかを切り替えられる。
- ドットファイルを表示するかどうかを切り替えられる。
  - ドットファイルとは、名前が「.」で始まるファイルまたはフォルダのことである（例: `.gitignore`、`.ssh`）。UNIX の慣習に従い、隠し属性が付いていなくても隠しファイルと同じように扱う。
  - 切り替えはツールバーの「ドットファイル」ボタンで行う（3.1）。ショートカットキーは Ctrl+Shift+H とする（`config.toml` で変更できる）。
  - 隠しファイルの切り替えとは独立している。隠し属性が付いたドットファイルは、両方の切り替えで「表示する」になっているときだけ表示する。
  - 初期状態（初回起動時）は「表示しない」とする。設定は `config.toml` に保存し、次回の起動時にも引き継ぐ。
  - ファイル一覧とナビゲーションツリーの両方に適用する。
- ファイルを外から追加・削除・変更したら、一覧に自動で反映する（ReadDirectoryChangesW などでフォルダを監視する）。

#### 6.1 絞り込み表示

今のタブのファイル一覧を、名前に指定の文字列を含む項目だけに絞り込んで表示できる。

- 始めかた: ファイル一覧にフォーカスがあるときに `/` キーを押すと、絞り込み入力モードになる。
  - ファイル一覧の下端に 1 行の入力欄が現れ、「/」に続けて入力した文字列が「絞り込み文字列」になる。入力欄の右端には「表示件数 / 全件数」（例: `3 / 42 件`）を出す。
  - 入力欄では日本語（IME）も入力できる。h / j / k / l も普通の文字として入力される。
- 一致の条件: 名前（拡張子を含む）に絞り込み文字列を含むファイルとフォルダだけを表示する。
  - 部分一致とし、英字の大文字と小文字は区別しない。ワイルドカードや正規表現は使わない。
  - 隠しファイル・ドットファイルの表示設定による絞り込みと組み合わせて働く（どちらの条件でも表示される項目だけを出す）。
  - 一致する項目が 1 つもないときは、一覧は空になり、件数は `0 / 42 件` のように表示する。
- 入力中のふるまい:
  - 1 文字入力・削除するごとに、すぐに一覧を絞り込み直す。
  - ↑ / ↓ キーで、絞り込まれた一覧の選択を動かせる。
  - Enter: 絞り込みを確定する。フォーカスはファイル一覧に戻り、絞り込んだ表示のまま、カーソル移動（hjkl を含む）やファイル操作を行える。何も選択していなければ先頭の項目を選ぶ。
  - Esc: 絞り込みを解除し、全件表示に戻す。入力欄は消え、フォーカスはファイル一覧に戻る。
  - 入力欄が空のときに Backspace を押した場合も、Esc と同じく解除する。
- 確定後のふるまい:
  - 入力欄は消さず、確定した絞り込み文字列と件数を表示し続ける（絞り込み中であることが分かるようにする）。
  - ファイル一覧で Esc を押すと、絞り込みを解除して全件表示に戻す。
  - もう一度 `/` を押すか入力欄をクリックすると、今の絞り込み文字列を編集できる。
  - ファイル操作の対象は、表示されている項目のうち選択したものだけとする。絞り込みで隠れた項目は選択から外し、すべて選択（Ctrl+A）も表示されている項目だけを選ぶ。
  - 外からのファイルの追加・名前の変更も絞り込みの条件に従って表示する（条件に合わない名前に変わった項目は一覧から消える）。
  - 最新の情報に更新（F5）しても絞り込みは保たれる。
- 絞り込みはタブごとに持つ。
  - 別のタブに切り替えて戻ってきても、そのタブの絞り込みは残っている。
  - そのタブで別のフォルダへ移動したとき（戻る / 進む / 上へを含む）は解除する。
  - ワークスペースには保存しない。tabex を起動し直すと、すべてのタブが絞り込みのない状態になる。

##### migemo による絞り込み

[rustmigemo](https://github.com/oguna/rustmigemo) が使える場合は、絞り込みに migemo を使い、ローマ字で入力した文字列で日本語の名前を絞り込めるようにする（例: `kaisha` で「会社案内.pdf」「かいしゃ.txt」「カイシャ.txt」が一致する）。

- 使う条件: tabex.exe と同じフォルダに `rustmigemo.dll` と辞書ファイル `migemo-compact-dict` の両方を置く。どちらも tabex には同梱せず、利用者が用意する（入手先は「使いかた」を参照）。
  - `rustmigemo.dll` がなければ、これまでどおりの部分一致だけで動く。何も表示しない。
  - `config.toml` に `migemo = false` と書くと、DLL があっても使わない。既定は `true`。
- 一致の条件: 「これまでの部分一致（大文字と小文字を区別しない）」**または**「入力した文字列から migemo が作るパターンに一致する」名前を表示する。migemo を使っても、それまで一致していた項目が一致しなくなることはない。
  - migemo のパターンも、英字の大文字と小文字を区別しない。
  - 名前の中のどこに一致してもよい（部分一致）。
  - そのほかの条件（隠しファイル・ドットファイルとの組み合わせ、件数の表示、追加・名前変更への追従、F5、タブごとに持つことなど）は、ここまでの絞り込みと同じ。
- 表示: migemo を使って絞り込んでいる間は、入力欄の右端の件数の左に `migemo` と表示する（例: `migemo  3 / 42 件`）。
- 読み込み:
  - DLL と辞書は、最初に絞り込みを始めたとき（`/` を押したとき）に読み込む。起動時間には影響させない。一度読み込んだら tabex を終了するまで使い続ける。
  - DLL はあるが、辞書が見つからない・読み込めない、または DLL を読み込めない（形式が違う、必要な関数がないなど）場合は、ステータスバーに「migemo を使えません: (理由)」と表示し、以後は部分一致だけで動く。この表示は tabex を起動している間に 1 度だけ出す。

#### 6.2 コマンド行

vi のコマンド行にならい、`:` に続けてコマンドを入力して実行できる。

- 始めかた: ファイル一覧にフォーカスがあるときに `:` を入力すると、ファイル一覧の下端に「:」で始まる 1 行の入力欄が現れる（絞り込み表示の入力欄と同じ位置）。
  - 絞り込み表示中に開いた場合は、コマンド行を閉じると絞り込みの入力欄（確定済みの文字列と件数）の表示に戻る。絞り込みそのものは変わらない。
- 入力欄でのキー操作:
  - Enter: 入力したコマンドを実行し、入力欄を閉じてファイル一覧にフォーカスを戻す。前後の空白は無視する。
  - Esc、または入力欄が空のときの Backspace: 何も実行せずに入力欄を閉じ、ファイル一覧にフォーカスを戻す。
- 知らないコマンドを入力した場合は何も実行せず、ステータスバーに「不明なコマンドです: (入力した文字列)」と表示する。
- 使えるコマンド:

| コマンド | 動き |
|---|---|
| `sh` | アクティブなタブが表示しているフォルダをカレントディレクトリにして、シェル（ターミナル）を起動する |

##### `:sh` でシェルを起動する

- シェルは tabex とは別のウィンドウで起動する。tabex は起動を待たずに操作を続けられる。
- 起動するシェル:
  - `config.toml` で起動するコマンドを指定できる（例は「使いかた」を参照）。
  - 指定がなければ、次の順に最初に見つかったものを使う: Windows Terminal（`wt.exe`）→ PowerShell 7（`pwsh.exe`）→ Windows PowerShell（`powershell.exe`）→ コマンドプロンプト（`cmd.exe`）。
- カレントディレクトリ:
  - タブが表示しているフォルダをそのまま使う。UNC パス（`\\server\share\...`）のフォルダでも起動する。ただしコマンドプロンプトは UNC パスをカレントディレクトリにできないため、コマンドプロンプトを使う場合は起動せずにステータスバーにその旨を表示する。
  - PC・ごみ箱・ネットワークなど、実際のフォルダではない場所を表示しているときは起動せず、ステータスバーに「このフォルダではシェルを開けません」と表示する。
  - 「フォルダが見つかりません」と表示しているタブでも、起動せずにその旨を表示する。
- 起動に失敗した場合（指定したコマンドが見つからないなど）は、ステータスバーにエラーを表示する。

### 7. 基本ファイル操作

- コピー / 切り取り / 貼り付け（Windows のクリップボードを使い、エクスプローラとの間でもやり取りできる）
- 削除（ごみ箱へ移す。Shift+Delete で完全に削除）
- 名前の変更（その場で編集。F2）
- フォルダを新しく作る（Ctrl+Shift+N）
- ドラッグ＆ドロップによるコピー・移動。ペイン間、タブ間、他のアプリとの間で使える。
- ファイル操作には Windows シェルの機能（IFileOperation）を使い、上書きの確認、進み具合の表示、元に戻す操作をエクスプローラと同じ動きにする。
- ダブルクリックや Enter でファイルを開くと、関連付けられたアプリが起動する。

### 8. Windows シェル統合

- 右クリックメニューはエクスプローラと同じものを出す（IContextMenu を使い、他のアプリが追加した項目も含める）。
- アイコンとサムネイルはシェルから取得し（IShellItemImageFactory など）、キャッシュする。
- 特殊フォルダを開ける: デスクトップ・ドキュメント・ダウンロード・PC・ネットワーク・ごみ箱など
- UNC パス（`\\server\share`）を扱える。
- プロパティ画面を開ける（Alt+Enter）。

### 9. キーボード操作

- 主な操作はすべてキーボードだけで行える。
- エクスプローラと同じショートカットを基本とする（F2、F5、Alt+←/→/↑、Ctrl+L、Backspace など）。
- Tab キーでアクティブペインを左右に切り替える。
- vi 風のカーソル移動として、h / j / k / l キーを使える。
  - 有効になるのは、ファイル一覧にフォーカスがあるときだけ。名前の変更中やアドレスバーへの入力中など、文字を入力している間は普通の文字として扱う。
  - 常に有効とする（切り替えの設定は設けない）。そのため、ファイル一覧で h / j / k / l の頭文字の項目へジャンプする標準の動きは使えなくなる。ほかの文字の頭文字ジャンプはそのまま使える。
  - j / k: アクティブなタブのファイル一覧で、選択を 1 つ下 / 上へ移す（↓ / ↑ キーと同じ）。先頭と末尾では止まり、反対の端へは回り込まない。
  - Shift+J / Shift+K: Shift+↓ / Shift+↑ と同じく、選択範囲を下 / 上へ広げる。
  - h / l: アクティブペインの中で、左 / 右隣のタブに切り替える（Ctrl+Shift+Tab / Ctrl+Tab と同じ）。タブの並び順は変えない。端のタブからは反対の端のタブへ回り込む。
  - ほかのショートカットと同じく、`config.toml` の `[keys]` で割り当てを変えられる。
- `/` キーで絞り込み表示を始める（6.1）。ファイル一覧にフォーカスがあるときだけ有効で、`config.toml` の `[keys]` で割り当てを変えられる。
- Alt+Home で、アクティブなタブをプライマリのホームディレクトリへ移動する（3.3）。文字入力中も含め、どこにフォーカスがあっても効く。
- Ctrl+U または Ctrl+B で、アクティブなタブを 1 つ上のフォルダへ移動する。
  - 動きは「上へ」（Alt+↑ / Backspace / 上へボタン）と同じとする。移動したあとは、元いたフォルダを選んだ状態にする。ドライブのルートからは PC へ移り、それより上がない場所では何もしない。
  - 戻るの履歴に積む点や、絞り込み表示を解除する点（6.1）も「上へ」と同じ。
  - ファイル一覧・ナビゲーションツリー・タブバーなど、文字入力をしていないところにフォーカスがあれば効く。名前の変更中・アドレスバーへの入力中・絞り込み文字列の入力中は効かない（何もしない）。
  - `config.toml` の `[keys]` で割り当てを変えられる。
- メニューバーがないため、Alt キーや、割り当てのない Alt+英字キーを押しても何もしない（メニューを開く動きはない）。Alt+F4・Alt+←/→/↑・Alt+D・Alt+Enter など割り当てのあるキーはこれまでどおり効く。
- `:` でコマンド行を開く（6.2）。ファイル一覧にフォーカスがあるときだけ有効で、`config.toml` の `[keys]` で割り当てを変えられる。キーボード配列（US 配列では Shift+;、日本語配列では : キー）によらず、「:」の文字を入力したときに開く。

### 10. 対象外（初期リリースには入れない）

- 高速検索（サブフォルダまで含めた検索）。今のフォルダの絞り込みは 6.1 で扱う。
- 1 つのウィンドウで複数のワークスペースを同時に開くこと、複数ウィンドウ間でワークスペースを同期すること
- 既定のファイルマネージャとして置き換える設定（Win+E の横取りなど）
- プレビューペイン
- テーマ切替（ダークモードは OS の設定に従う程度にとどめる）
- OneDrive の同期状態のオーバーレイ表示、OneDrive 以外のクラウドストレージ（iCloud Drive など）のナビゲーションツリーへの表示
- ARM64 版

## 使いかた

### 起動

```
tabex.exe                      # 前回使っていたワークスペースを復元して起動する
tabex.exe C:\Users\me\Desktop  # アクティブペインに新しいタブを作り、指定のフォルダを開く（今のワークスペースに追加する。複数指定できる）
tabex.exe --workspace dev      # ワークスペース "dev" を開いて起動する（起動中なら "dev" に切り替える）
tabex.exe --help               # 使いかたを表示する
tabex.exe --version            # バージョンを表示する（例: tabex 0.1.0）
```

- 存在しないフォルダ・ワークスペースを指定した場合や、不正な引数を渡した場合は、エラーメッセージを表示し、ウィンドウを開かずに終了コード 2 で終了する。
- tabex がすでに起動している場合は、引数を起動中のウィンドウに渡し、終了コード 0 ですぐ終了する。

### ワークスペースを使う流れ

1. 左ペインで `C:\src\project`、`C:\src\project\docs` を、右ペインで `D:\data` をタブで開く。
2. ナビゲーションツリーの「ワークスペース」ノードを右クリックし、「今の構成を元に新規作成...」で `dev` と名付ける。
3. 以後のタブ操作やフォルダ移動は自動で `dev` に保存される。
4. Ctrl+Alt+W を押してワークスペース一覧から `photo` を選ぶと、ウィンドウ全体が `photo` のタブ構成に切り替わる。ナビゲーションツリーの「ワークスペース」の下に並んでいる `photo` をクリックしても同じように切り替わり、`photo` が太字になる。
5. アプリを終了して起動し直すと、最後に使っていた `photo` が復元される。

### ワークスペースファイルの例（`%APPDATA%\tabex\workspaces\dev.toml`）

```toml
version = 1
name = "dev"
active_pane = "left"
layout = "dual"        # "single" | "dual"
split_ratio = 0.5

[left]
active_tab = 0

[[left.tabs]]
path = 'C:\src\project'
view = "details"       # "details" | "list" | "icons_large" | "icons_medium" | "icons_small"
sort = { column = "name", order = "asc" }
columns = [
  { id = "name", width = 320 },
  { id = "modified", width = 160 },
  { id = "type", width = 120 },
  { id = "size", width = 100 },
]

[[left.tabs]]
path = 'C:\src\project\docs'
view = "list"
sort = { column = "modified", order = "desc" }

[right]
active_tab = 0

[[right.tabs]]
path = 'D:\data'
view = "details"
sort = { column = "name", order = "asc" }
```

### ホームディレクトリを登録して移動する

`config.toml` に次のように書いて起動する。

```toml
# %APPDATA%\tabex\config.toml
[[homes]]              # the first one is the primary home
name = "仕事"
path = 'D:\work'

[[homes]]
name = "個人"
path = '%USERPROFILE%'

[[homes]]              # name may be omitted
path = '\\nas\share'

[keys]
"Ctrl+Shift+Home" = "GoHome"   # extra key for the primary home (default: Alt+Home)
```

1. ツールバーの左端の「ホーム」ボタンを左クリック（または Alt+Home）すると、アクティブなタブが `D:\work` に移動する。
2. 右クリックすると、ボタンの下に次の一覧が出る。今表示しているフォルダには印が付く。

   ```
   仕事    D:\work
   個人    C:\Users\me
   \\nas\share
   ```

3. 「個人」を選ぶと、アクティブなタブが `C:\Users\me` に移動する。戻る（Alt+←）で元のフォルダに戻れる。
4. `[[homes]]` を 1 つも書かなければ、ホームボタンはユーザーフォルダ（`C:\Users\me`）へ移動し、右クリックの一覧にもそれだけが出る。

### migemo で絞り込む

1. [rustmigemo](https://github.com/oguna/rustmigemo) を `cargo build --features windows-dll --target x86_64-pc-windows-msvc --release` でビルドし、できた `rustmigemo.dll` を tabex.exe と同じフォルダに置く。
2. [migemo-compact-dict-latest](https://github.com/oguna/migemo-compact-dict-latest) のリリースから `migemo-compact-dict` をダウンロードし、同じフォルダに置く。

```
C:\tools\tabex\
  tabex.exe
  rustmigemo.dll
  migemo-compact-dict
```

3. tabex を起動し、ファイル一覧で `/` を押して `kaisha` と入力すると、「会社案内.pdf」「かいしゃ.txt」「カイシャ.txt」などが表示される。入力欄の右端は `migemo  3 / 42 件` のようになる。
4. migemo を使いたくないときは、`config.toml` に次のように書く。

```toml
# %APPDATA%\tabex\config.toml
migemo = false
```

```
▸ ワークスペース
▸ ホーム
```

「OneDrive - Personal」をクリックすると、アクティブなタブで `C:\Users\me\OneDrive` が開き、アドレスバーは `Users › me › OneDrive` になる。OneDrive を設定していない PC では、OneDrive の項目は出ない。項目の名前はエクスプローラと同じなので、Windows のバージョンや設定によっては「OneDrive - Personal」ではなく「（ユーザー名） - 個人用」のように表示される。

### コマンド行からシェルを開く

1. ファイル一覧で `:` を入力すると、一覧の下端に `:` の入力欄が現れる。
2. `sh` と入力して Enter を押すと、タブが表示しているフォルダをカレントディレクトリにしてシェルが新しいウィンドウで開く。
3. 使うシェルを決めたい場合は、`config.toml` にコマンドを書く。書かなければ Windows Terminal → PowerShell 7 → Windows PowerShell → コマンドプロンプトの順に、見つかったものを使う。

```toml
# %APPDATA%\tabex\config.toml
shell = 'pwsh.exe -NoLogo'
```
