# tabex 要求仕様

## 概要

tabex は Windows 標準エクスプローラの代わりに使うファイルマネージャである。

- Rust で実装し、起動が速く、メモリ消費の少ない軽快な動作を目指す。
- 「ワークスペース」機能を中心に据える。ワークスペースとは、複数のフォルダをまとめて開き、タブで切り替えられる作業単位のことである。名前を付けて保存しておき、あとからいつでも同じ構成を開き直せる。
- 左右 2 ペイン表示とし、それぞれのペインが独自のタブ列を持つ。
- Windows シェルと統合し、エクスプローラと同じ右クリックメニュー・アイコン・サムネイルを使える。

## 要求仕様

### 1. 動作環境・実装制約

- 対象 OS: Windows 10 (22H2) 以降 / Windows 11、x64（ARM64 は将来対応）
- 実装言語: Rust（stable toolchain）
- GUI: `windows` crate（windows-rs）経由で Win32 API / COM を直接使う。Web ランタイム（WebView2 など）や大型の GUI フレームワークには依存しない。
- 配布形態: インストール不要の単一 exe で動作すること（インストーラは任意）
- 高 DPI（Per-Monitor V2）に対応すること
- 日本語のファイル名・パス・IME 入力（リネーム時など）を正しく扱えること
- 長いパス（260 文字を超えるパス）を扱えること

### 2. 性能目標

| 項目 | 目標 |
|---|---|
| 起動から操作可能になるまで（コールドスタート、前回ワークスペース復元を含む） | 300ms 以内 |
| 待機時のメモリ使用量（ワーキングセット） | 50MB 以下 |
| 10 万件のファイルを含むフォルダを開いたとき | UI が固まらないこと（列挙はバックグラウンドで行い、終わった分から順に表示する） |
| フォルダ移動・タブ切替の応答 | 体感で遅延がないこと（目安 100ms 以内） |

- ファイル列挙・アイコンやサムネイルの取得・ファイル操作は UI スレッドとは別のスレッドで行う。
- 一覧表示は仮想化し、画面に見えている行だけを描画する。

### 3. ウィンドウ構成

- 1 つのウィンドウの中に、左右 2 つのペインを並べる。
  - ペインの境界はドラッグで幅を変えられる。
  - 1 ペイン表示にも切り替えられる。
- 各ペインは独自のタブ列を持ち、**1 タブ = 1 フォルダ** を表示する。
- 操作対象となるペインは常に 1 つで（アクティブペイン）、見た目で区別できる。
- 各タブには次の部品を備える。
  - アドレスバー（パンくず形式。クリックするとパスを直接入力できる）
  - 戻る / 進む / 上へ ボタン
  - ファイル一覧
- ウィンドウ左側にナビゲーションツリー（ワークスペース・クイックアクセス・ドライブ・フォルダ階層）を置く。表示/非表示を切り替えられる。
  - ナビゲーションツリーの一番上に「ワークスペース」ノードを置き、その子として登録されているワークスペースを並べる（詳細は 5.6）。
- ステータスバーに、項目数・選択している数・選択した項目の合計サイズを表示する。

### 4. タブ操作

- タブを新しく開く（Ctrl+T）、閉じる（Ctrl+W）、切り替える（Ctrl+Tab / Ctrl+Shift+Tab / Ctrl+1〜9）
- ドラッグでタブの並び順を変えられる。タブを反対側のペインへ移すこともできる。
- フォルダを中クリックすると、そのフォルダを新しいタブで開く。
- 閉じたタブを開き直せる（Ctrl+Shift+T）。
- タブを複製できる。

### 5. ワークスペース

#### 5.1 定義

ワークスペースとは、名前の付いた「左右ペインのタブ構成」と「表示状態」の組である。

#### 5.2 保存・復元する情報

- ワークスペース名
- 左右それぞれのペインについて
  - タブの並び順と、各タブで開いているフォルダのパス
  - アクティブなタブ
  - 各タブの表示状態: 表示モード（詳細 / 一覧 / アイコン）、ソート列と昇順・降順、列の構成と列幅
- アクティブペイン、ペイン分割の比率、1 ペイン / 2 ペインの別

以下は保存しない: ファイルの選択状態、スクロール位置、戻る / 進むの履歴

#### 5.3 管理操作

- 新規作成: 空の構成か、今の構成を元に作る
- 名前を付けて保存（今の構成を別名で複製する）
- 名前の変更、削除
- 切り替え: メニューから選ぶ、ショートカット（Ctrl+Alt+W でワークスペース一覧を表示）、最近使ったワークスペース一覧から選ぶ、ナビゲーションツリーの「ワークスペース」ノードから選ぶ（5.6）

#### 5.4 保存と起動のふるまい

- 変更は自動で保存する。タブの開閉・移動、フォルダ移動、表示状態の変更をきっかけに、短い間隔で間引いて書き込む。
- 起動すると、前回最後に使っていたワークスペースを復元する。
- 1 つのウィンドウで同時に開けるワークスペースは 1 つだけ。切り替えると、今のワークスペースを保存してから次のワークスペースを読み込む。
- tabex は同時に 1 つしか起動しない（単一インスタンス）。すでに起動しているときに tabex.exe をもう一度実行すると、引数を起動中のウィンドウに渡してすぐ終了する。これにより、同じワークスペースファイルを複数のプロセスが同時に書き込むことを防ぐ。
- 復元時に、保存されているフォルダが見つからない場合（削除済み・ネットワークが未接続など）でも、ワークスペース全体の復元は止めない。該当するタブには「フォルダが見つかりません」と表示し、再試行と、一番近い親フォルダへ移動する操作を用意する。保存されているパスは書き換えない。

#### 5.5 保存形式

- 形式: TOML
- 保存場所: `%APPDATA%\tabex\workspaces\<ワークスペース名>.toml`（1 ワークスペースにつき 1 ファイル）
- アプリ全体の設定: `%APPDATA%\tabex\config.toml`（前回使っていたワークスペース名、ショートカット設定など）
- 利用者が手で編集したり、他人と共有したりできる形式とする。読み込めないファイルがあれば、そのファイルだけを使わずにエラーを通知し、アプリは起動を続ける。

#### 5.6 ナビゲーションツリーのワークスペースノード

- ナビゲーションツリーの最上位の先頭（クイックアクセスより上）に「ワークスペース」ノードを置く。その子として、登録されているワークスペースをすべて並べる。
  - 並び順は名前の自然順とする（最近使った順の一覧は Ctrl+Alt+W のワークスペース一覧が担う）。
  - ワークスペースの項目は末端の項目とし、その下にフォルダなどの子は持たない。
  - 読み込めないワークスペースファイル（5.5）は並べない。
- 項目をクリックすると、そのワークスペースに切り替える。キーボードで項目を選んだ場合も同様に切り替える（エクスプローラのナビゲーションツリーで項目を選んだときと同じ感覚）。切り替えのふるまいは 5.4 に従う（今のワークスペースを保存してから読み込む）。
  - すでに開いているワークスペースの項目を選んだときは何もしない。
- 今開いているワークスペースの項目は太字で表示し、ほかの項目と区別できるようにする。
- 右クリックメニュー:
  - ワークスペースの項目: 名前の変更、削除。削除するときは確認ダイアログを出す。今開いているワークスペースを削除することはできない（メニュー項目を無効にする）。
  - 「ワークスペース」ノード: 新規作成（5.3 と同じく、空の構成か今の構成を元にするかを選ぶ）
- ワークスペースの作成・名前の変更・削除・切り替えを行ったら（メニュー、ワークスペース一覧、ツリーのどこから行った場合でも）、ツリーの内容と太字表示をすぐに更新する。
- 「ワークスペース」ノードの展開 / 折りたたみの状態は `config.toml` に保存し、次回の起動時にも引き継ぐ。初回起動時は展開した状態とする。
- ナビゲーションツリーを非表示にすると、「ワークスペース」ノードも一緒に隠れる。

### 6. ファイル一覧表示

- 表示モード: 詳細（列表示） / 一覧 / アイコン（大・中・小）
- 詳細表示の列: 名前・更新日時・種類・サイズを標準とする。列の追加・削除、並べ替え、幅の変更ができる。
- 列見出しをクリックしてソートできる。名前は自然順（例: `file2` を `file10` より前に並べる）で並べる。
- 隠しファイル・システムファイル・拡張子を表示するかどうかを切り替えられる。
- ドットファイルを表示するかどうかを切り替えられる。
  - ドットファイルとは、名前が「.」で始まるファイルまたはフォルダのことである（例: `.gitignore`、`.ssh`）。UNIX の慣習に従い、隠し属性が付いていなくても隠しファイルと同じように扱う。
  - 切り替えは「表示」メニューの「ドットファイル」で行う。ショートカットキーは Ctrl+Shift+H とする（`config.toml` で変更できる）。
  - 隠しファイルの切り替えとは独立している。隠し属性が付いたドットファイルは、両方の切り替えで「表示する」になっているときだけ表示する。
  - 初期状態（初回起動時）は「表示しない」とする。設定は `config.toml` に保存し、次回の起動時にも引き継ぐ。
  - ファイル一覧とナビゲーションツリーの両方に適用する。
- ファイルを外から追加・削除・変更したら、一覧に自動で反映する（ReadDirectoryChangesW などでフォルダを監視する）。

#### 6.1 絞り込み表示

今のタブのファイル一覧を、名前に指定の文字列を含む項目だけに絞り込んで表示できる。

- 始めかた: ファイル一覧にフォーカスがあるときに `/` キーを押すと、絞り込み入力モードになる。
  - ファイル一覧の下端に 1 行の入力欄が現れ、「/」に続けて入力した文字列が「絞り込み文字列」になる。入力欄の右端には「表示件数 / 全件数」（例: `3 / 42 件`）を出す。
  - 入力欄では日本語（IME）も入力できる。h / j / k / l も普通の文字として入力される。
- 一致の条件: 名前（拡張子を含む）に絞り込み文字列を含むファイルとフォルダだけを表示する。
  - 部分一致とし、英字の大文字と小文字は区別しない。ワイルドカードや正規表現は使わない。
  - 隠しファイル・ドットファイルの表示設定による絞り込みと組み合わせて働く（どちらの条件でも表示される項目だけを出す）。
  - 一致する項目が 1 つもないときは、一覧は空になり、件数は `0 / 42 件` のように表示する。
- 入力中のふるまい:
  - 1 文字入力・削除するごとに、すぐに一覧を絞り込み直す。
  - ↑ / ↓ キーで、絞り込まれた一覧の選択を動かせる。
  - Enter: 絞り込みを確定する。フォーカスはファイル一覧に戻り、絞り込んだ表示のまま、カーソル移動（hjkl を含む）やファイル操作を行える。何も選択していなければ先頭の項目を選ぶ。
  - Esc: 絞り込みを解除し、全件表示に戻す。入力欄は消え、フォーカスはファイル一覧に戻る。
  - 入力欄が空のときに Backspace を押した場合も、Esc と同じく解除する。
- 確定後のふるまい:
  - 入力欄は消さず、確定した絞り込み文字列と件数を表示し続ける（絞り込み中であることが分かるようにする）。
  - ファイル一覧で Esc を押すと、絞り込みを解除して全件表示に戻す。
  - もう一度 `/` を押すか入力欄をクリックすると、今の絞り込み文字列を編集できる。
  - ファイル操作の対象は、表示されている項目のうち選択したものだけとする。絞り込みで隠れた項目は選択から外し、すべて選択（Ctrl+A）も表示されている項目だけを選ぶ。
  - 外からのファイルの追加・名前の変更も絞り込みの条件に従って表示する（条件に合わない名前に変わった項目は一覧から消える）。
  - 最新の情報に更新（F5）しても絞り込みは保たれる。
- 絞り込みはタブごとに持つ。
  - 別のタブに切り替えて戻ってきても、そのタブの絞り込みは残っている。
  - そのタブで別のフォルダへ移動したとき（戻る / 進む / 上へを含む）は解除する。
  - ワークスペースには保存しない。tabex を起動し直すと、すべてのタブが絞り込みのない状態になる。

### 7. 基本ファイル操作

- コピー / 切り取り / 貼り付け（Windows のクリップボードを使い、エクスプローラとの間でもやり取りできる）
- 削除（ごみ箱へ移す。Shift+Delete で完全に削除）
- 名前の変更（その場で編集。F2）
- フォルダを新しく作る（Ctrl+Shift+N）
- ドラッグ＆ドロップによるコピー・移動。ペイン間、タブ間、他のアプリとの間で使える。
- ファイル操作には Windows シェルの機能（IFileOperation）を使い、上書きの確認、進み具合の表示、元に戻す操作をエクスプローラと同じ動きにする。
- ダブルクリックや Enter でファイルを開くと、関連付けられたアプリが起動する。

### 8. Windows シェル統合

- 右クリックメニューはエクスプローラと同じものを出す（IContextMenu を使い、他のアプリが追加した項目も含める）。
- アイコンとサムネイルはシェルから取得し（IShellItemImageFactory など）、キャッシュする。
- 特殊フォルダを開ける: デスクトップ・ドキュメント・ダウンロード・PC・ネットワーク・ごみ箱など
- UNC パス（`\\server\share`）を扱える。
- プロパティ画面を開ける（Alt+Enter）。

### 9. キーボード操作

- 主な操作はすべてキーボードだけで行える。
- エクスプローラと同じショートカットを基本とする（F2、F5、Alt+←/→/↑、Ctrl+L、Backspace など）。
- Tab キーでアクティブペインを左右に切り替える。
- vi 風のカーソル移動として、h / j / k / l キーを使える。
  - 有効になるのは、ファイル一覧にフォーカスがあるときだけ。名前の変更中やアドレスバーへの入力中など、文字を入力している間は普通の文字として扱う。
  - 常に有効とする（切り替えの設定は設けない）。そのため、ファイル一覧で h / j / k / l の頭文字の項目へジャンプする標準の動きは使えなくなる。ほかの文字の頭文字ジャンプはそのまま使える。
  - j / k: アクティブなタブのファイル一覧で、選択を 1 つ下 / 上へ移す（↓ / ↑ キーと同じ）。先頭と末尾では止まり、反対の端へは回り込まない。
  - Shift+J / Shift+K: Shift+↓ / Shift+↑ と同じく、選択範囲を下 / 上へ広げる。
  - h / l: アクティブペインの中で、左 / 右隣のタブに切り替える（Ctrl+Shift+Tab / Ctrl+Tab と同じ）。タブの並び順は変えない。端のタブからは反対の端のタブへ回り込む。
  - ほかのショートカットと同じく、`config.toml` の `[keys]` で割り当てを変えられる。
- `/` キーで絞り込み表示を始める（6.1）。ファイル一覧にフォーカスがあるときだけ有効で、`config.toml` の `[keys]` で割り当てを変えられる。

### 10. 対象外（初期リリースには入れない）

- 高速検索（サブフォルダまで含めた検索）。今のフォルダの絞り込みは 6.1 で扱う。
- 1 つのウィンドウで複数のワークスペースを同時に開くこと、複数ウィンドウ間でワークスペースを同期すること
- 既定のファイルマネージャとして置き換える設定（Win+E の横取りなど）
- プレビューペイン
- テーマ切替（ダークモードは OS の設定に従う程度にとどめる）
- ARM64 版

## 使いかた

### 起動

```
tabex.exe                      # 前回使っていたワークスペースを復元して起動する
tabex.exe C:\Users\me\Desktop  # アクティブペインに新しいタブを作り、指定のフォルダを開く（今のワークスペースに追加する。複数指定できる）
tabex.exe --workspace dev      # ワークスペース "dev" を開いて起動する（起動中なら "dev" に切り替える）
tabex.exe --help               # 使いかたを表示する
tabex.exe --version            # バージョンを表示する（例: tabex 0.1.0）
```

- 存在しないフォルダ・ワークスペースを指定した場合や、不正な引数を渡した場合は、エラーメッセージを表示し、ウィンドウを開かずに終了コード 2 で終了する。
- tabex がすでに起動している場合は、引数を起動中のウィンドウに渡し、終了コード 0 ですぐ終了する。

### ワークスペースを使う流れ

1. 左ペインで `C:\src\project`、`C:\src\project\docs` を、右ペインで `D:\data` をタブで開く。
2. メニュー「ワークスペース > 名前を付けて保存」で `dev` と名付ける。
3. 以後のタブ操作やフォルダ移動は自動で `dev` に保存される。
4. Ctrl+Alt+W を押してワークスペース一覧から `photo` を選ぶと、ウィンドウ全体が `photo` のタブ構成に切り替わる。ナビゲーションツリーの「ワークスペース」の下に並んでいる `photo` をクリックしても同じように切り替わり、`photo` が太字になる。
5. アプリを終了して起動し直すと、最後に使っていた `photo` が復元される。

### ワークスペースファイルの例（`%APPDATA%\tabex\workspaces\dev.toml`）

```toml
version = 1
name = "dev"
active_pane = "left"
layout = "dual"        # "single" | "dual"
split_ratio = 0.5

[left]
active_tab = 0

[[left.tabs]]
path = 'C:\src\project'
view = "details"       # "details" | "list" | "icons_large" | "icons_medium" | "icons_small"
sort = { column = "name", order = "asc" }
columns = [
  { id = "name", width = 320 },
  { id = "modified", width = 160 },
  { id = "type", width = 120 },
  { id = "size", width = 100 },
]

[[left.tabs]]
path = 'C:\src\project\docs'
view = "list"
sort = { column = "modified", order = "desc" }

[right]
active_tab = 0

[[right.tabs]]
path = 'D:\data'
view = "details"
sort = { column = "name", order = "asc" }
```
