# tabex

tabex は、Windows のエクスプローラの代わりに使える、軽くて速いファイルマネージャです。Rust で書かれており、Win32 API を直接使っています。

- **ワークスペース**: 複数のフォルダをタブで開いた構成に名前を付けて保存し、いつでも切り替えられます。
- **2 ペイン**: 左右のペインが、それぞれ独立したタブ列を持ちます。
- **エクスプローラと同じ操作**: 右クリックメニュー、アイコン、サムネイル、コピー・移動・削除、ドラッグ＆ドロップ、元に戻す（Ctrl+Z）が使えます。
- **軽さ**: exe は 1 つだけ（約 1MB）で、ランタイムのインストールは不要です。起動は約 0.1 秒で、10 万件のフォルダも固まらずに開けます。

## 必要な環境

- Windows 10 (22H2) 以降、または Windows 11（x64）

### ソースからビルドする場合

- Rust stable（`x86_64-pc-windows-msvc` ツールチェーン）
- Visual Studio Build Tools 2022（「C++ によるデスクトップ開発」の VC ツール）

## インストール

インストーラはありません。`tabex.exe` を好きな場所に置いて実行するだけです。

ソースからビルドする手順:

```
cargo build --release
```

`target\release\tabex.exe` ができます。

> cargo は `%USERPROFILE%\.cargo\bin` にインストールされます。シェルによってはこのフォルダが PATH に入っていないので、その場合は PATH に追加するか、`cargo.exe` をフルパスで実行してください。

## 使いかた

### 起動

```
tabex.exe                      # 前回使っていたワークスペースを開いて起動する
tabex.exe C:\Users\me\Desktop  # アクティブペインに新しいタブを作り、指定のフォルダを開く（複数指定できる）
tabex.exe --workspace dev      # ワークスペース "dev" を開く（起動中なら "dev" に切り替える）
tabex.exe --help               # 使いかたを表示する
tabex.exe --version            # バージョンを表示する
```

`--version` の出力例:

```
> start /wait "" tabex.exe --version
tabex 0.1.0
```

- 存在しないフォルダやワークスペースを指定した場合、または不正な引数を渡した場合は、エラーメッセージを表示して終了コード 2 で終わります。
- tabex は同時に 1 つしか起動しません。起動中にもう一度実行すると、引数を起動中のウィンドウに渡して、すぐ終了します（終了コード 0）。
- tabex は GUI アプリなので、`cmd` から終了コードを確かめるときは `start /wait` を付けて実行してください。付けないと、終了を待たずに次の行へ進んでしまいます。

### ワークスペース

1. 左右のペインで、使いたいフォルダをタブで開きます。
2. メニュー「ワークスペース > 名前を付けて保存」で名前（例: `dev`）を付けます。
3. 以後のタブの操作やフォルダの移動は、自動で保存されます（変更から 1 秒後、または終了時）。
4. **Ctrl+Alt+W** で一覧を開き、別のワークスペースを選ぶと、ウィンドウ全体がそのタブ構成に切り替わります。一覧の項目を右クリックすると、名前の変更と削除ができます。
   - 左側のナビゲーションツリーの一番上にある「ワークスペース」の下にも、登録済みのワークスペースが名前順に並んでいます。クリックするだけで切り替えられ、今開いているものは太字で表示されます。項目を右クリックすると名前の変更と削除、「ワークスペース」を右クリックすると新規作成ができます。
5. 次に起動したときは、最後に使っていたワークスペースが開きます。

保存されているフォルダが見つからない場合（削除済みやネットワークの未接続など）、そのタブには「フォルダが見つかりません」と表示され、「再試行」と「親フォルダへ」のボタンが出ます。

### 主なキー操作

| キー | 操作 | キー | 操作 |
|---|---|---|---|
| Ctrl+T / Ctrl+W | タブを開く / 閉じる | Ctrl+Shift+T | 閉じたタブを開き直す |
| Ctrl+Tab / Ctrl+Shift+Tab | 次 / 前のタブ | Ctrl+1〜9 | タブを選ぶ（9 は最後のタブ） |
| Tab | 左右のペインを切り替える | Ctrl+Alt+W | ワークスペースの一覧 |
| Alt+← / Alt+→ / Alt+↑, Backspace, Ctrl+U, Ctrl+B | 戻る / 進む / 上へ | Ctrl+L, Alt+D, F4 | パスを直接入力する |
| Enter / Ctrl+Enter | 開く / 新しいタブで開く | F5 | 最新の情報に更新 |
| F2 | 名前の変更 | Ctrl+Shift+N | 新しいフォルダー |
| Ctrl+C / Ctrl+X / Ctrl+V | コピー / 切り取り / 貼り付け | Delete / Shift+Delete | ごみ箱へ / 完全に削除 |
| Ctrl+Z | 元に戻す | Alt+Enter | プロパティ |
| Ctrl+H | 隠しファイルの表示を切り替える | Ctrl+Shift+H | ドットファイルの表示を切り替える |
| Ctrl+Shift+1〜5 | 大 / 中 / 小アイコン / 一覧 / 詳細 | | |
| j / k | 選択を 1 つ下 / 上へ（vi 風） | Shift+J / Shift+K | 選択範囲を下 / 上へ広げる |
| h / l | 左 / 右隣のタブへ（端では反対の端へ回り込む） | / / Esc | 絞り込み表示を始める / 解除する |
| : | コマンド行を開く（`:sh` でシェル） | | |

h / j / k / l はファイル一覧にフォーカスがあるときだけ効きます。名前の変更中やパスの入力中は普通の文字として入力され、ナビゲーションツリーでは頭文字ジャンプになります。ファイル一覧で h / j / k / l の頭文字ジャンプを使いたい場合は、`config.toml` の `[keys]` に `"J" = "None"` のように書くと、そのキーの割り当てを外せます。

Ctrl+U / Ctrl+B は「上へ」と同じく 1 つ上のフォルダへ移動します（元いたフォルダが選ばれた状態になります）。名前の変更中・パスの入力中・絞り込み文字列の入力中は何もしません。

### 絞り込み表示

ファイル一覧で `/` を押すと一覧の下に入力欄が現れ、入力した文字列を名前に含むファイルとフォルダだけが表示されます（部分一致、英字の大文字・小文字は区別しません）。入力欄の右端には「表示件数 / 全件数」が出ます。

- 入力中は 1 文字ごとに一覧が絞り込まれ、↑ / ↓ で選択を動かせます。
- Enter で絞り込みを確定し、一覧に戻ります。そのままカーソル移動やファイル操作ができます。操作の対象は表示されている項目だけで、Ctrl+A も表示中の項目だけを選びます。
- Esc（入力中でも一覧でも）、または入力欄が空のときの Backspace で解除し、全件表示に戻ります。
- 確定後にもう一度 `/` を押すか入力欄をクリックすると、文字列を編集できます。
- 絞り込みはタブごとに保たれ、別のフォルダへ移動すると解除されます。ワークスペースには保存されません。

### コマンド行（`:sh` でシェルを開く）

ファイル一覧で `:` を入力すると、一覧の下に `:` の入力欄が現れます（US 配列なら Shift+;、日本語配列なら : キー）。コマンドを入力して Enter で実行し、Esc（または空のときの Backspace）で取り消します。

| コマンド | 動き |
|---|---|
| `sh` | タブが表示しているフォルダをカレントディレクトリにして、シェルを別ウィンドウで開く |

- 使うシェルは、`config.toml` に `shell = '...'` を書いて指定できます。書かなければ Windows Terminal → PowerShell 7 → Windows PowerShell → コマンドプロンプトの順に、見つかったものを使います。
- PC・ごみ箱など実際のフォルダではない場所では開けません。コマンドプロンプトは UNC パス（`\\server\share`）のフォルダでは開けません。

名前が「.」で始まるファイルやフォルダ（ドットファイル。例: `.gitignore`、`.ssh`）は、UNIX の慣習に従い、初期状態では表示しません。「表示」メニューの「ドットファイル」で、隠しファイルとは別に表示を切り替えられます。

タブは、ドラッグで並べ替えたり反対側のペインへ移したりできます。中クリックで閉じ、ダブルクリックで複製します。

### 設定ファイル

| ファイル | 内容 |
|---|---|
| `%APPDATA%\tabex\config.toml` | 前回のワークスペース、最近使ったワークスペース、表示設定（ナビゲーションツリーの「ワークスペース」の開閉を含む）、ウィンドウ位置、キー割り当て、`:sh` で開くシェル |
| `%APPDATA%\tabex\workspaces\<名前>.toml` | ワークスペース（1 ファイルにつき 1 つ） |

どちらも TOML 形式なので、手で編集したり他の人と共有したりできます。キー割り当ては `config.toml` で変えられます。

```toml
shell = 'pwsh.exe -NoLogo'   # :sh で開くシェル（省略時は自動で選ぶ）

[keys]
"Ctrl+Q" = "NewTab"     # 割り当てを追加する
"Ctrl+H" = "None"       # 既定の割り当てを外す
":" = "None"            # 記号 1 文字は、入力された文字で割り当てる
```

ワークスペースファイルの書式は [doc/requirement.md](doc/requirement.md) の「使いかた」に例があります。

## 開発者向け

### テスト

```
cargo test --release
```

- 単体テストは、Windows に依存しないロジック（タブ操作、ワークスペースの直列化、レイアウト計算、コマンドライン解析など）を対象にしています。
- 結合テスト（`tests/`）は、フォルダの列挙・変更の監視・設定の保存を、実際のファイルシステム上で確かめます。Windows 上で実行してください。

静的解析:

```
cargo clippy --release --all-targets -- -D warnings
```

### 性能の計測

```
cargo run --release --example enum_bench -- %TEMP%\tabex_bench --create 100000
```

10 万件のフォルダを作り、最初のチャンクが届くまでの時間、全件の列挙にかかった時間、並べ替えにかかった時間を表示します。

### 開発用の環境変数

| 変数 | 効果 |
|---|---|
| `TABEX_HOME` | 設定とワークスペースの保存先を、`%APPDATA%\tabex` の代わりにこのフォルダにする。普段の設定を汚さずに試せる。単一インスタンスの判定もこのフォルダごとに行うので、普段使いの tabex と同時に起動できる |
| `TABEX_TRACE` | 起動の各段階にかかった時間と、実行したコマンドを `%LOCALAPPDATA%\tabex\trace.log` に記録する |

予期しないエラーで終了した場合は、`%LOCALAPPDATA%\tabex\crash.log` に詳細が残ります。
